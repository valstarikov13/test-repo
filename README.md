# Swap Demo

Мини-проект на Bash, показывающий разные способы обмена значениями между переменными и массивами.

## Что демонстрирует

- Классический обмен через временную переменную.
- Обмен целых чисел без временной переменной (арифметика).
- Обмен строк через `read`.
- Универсальную функцию `swap_by_name`, меняющую переменные по их именам.
- Обмен содержимым массивов.

## Запуск

```bash
bash swap.sh
```

Или сделайте скрипт исполняемым:

```bash
chmod +x swap.sh
./swap.sh
```

## Требования

- Bash 4.0 или новее.
